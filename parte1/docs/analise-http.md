# Parágrafo

- Para listar um filmes no cinetrack podemos usar dois métodos, o método mais comum é o get que tem como objetivo buscar informações de um determinado filme, e o método post que tem como objetivo enviar informações para o servidor e receber uma resposta do mesmo, como por exemplo, enviar filtros de pesquisa para o servidor e receber uma lista de filmes que atendam a esses filtros.

- no corpo da resposta percisamos receber as informações do filme, como o título, a sinopse, a data de lançamento, o elenco, a classificação etária, entre outros. Essas informações podem ser exibidas na tela para o usuário. Além disso precisaremos receber a imagem do filme, que pode ser exibida junto com as informações do filme. A imagem pode ser recebida como um link para a imagem hospedada em algum servidor, ou como um arquivo binário que pode ser exibido diretamente na tela.
